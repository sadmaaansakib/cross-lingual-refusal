A **reproducible research scaffold** for analyzing whether harmful-versus-harmless
refusal representations align between **English and Bangla** in frozen instruction-tuned
language models (Qwen2.5-7B-Instruct and Meta-Llama-3-8B-Instruct).

> **Scope:** This repository performs *representation analysis only* — it does **not**
> fine-tune models, generate responses, or weaken any deployed safety mechanism. Use only
> institutionally approved safety benchmarks and keep sensitive benchmark files in restricted storage.

## Overview

This project investigates the **cross-lingual transferability of refusal direction vectors**
in large language models. Given a bilingual dataset of semantically paired harmful/harmless
prompts in English and Bangla, we:

1. Extract hidden-state activations at every transformer layer for each language.
2. Estimate a **difference-in-means (DiM) direction** per layer that separates harmful from harmless representations.
3. Measure the **cosine similarity** between English and Bangla DiM directions.
4. Evaluate **cross-language transfer**: does an English-derived direction correctly classify Bangla prompts and vice versa?
5. Run **four negative-control baselines** to rule out spurious explanations.

This is inspired by and builds upon Arditi et al. (2024), *"Refusal in Language Models Is Mediated by a Single Direction"*.

## Dataset Preparation

The dataset is a bilingual CSV of semantically matched harmful/harmless prompt pairs in
English (`en_prompt`) and Bangla (`bn_prompt`). Each pair shares a `pair_id`, a `category`,
a `label` (`harmful` | `harmless`), and a `split` (`train` | `validation` | `test`).

**Required columns:**
```
pair_id, category, en_prompt, bn_prompt, label, split,
translation_status, difficulty, source, notes
```

1. Obtain an institutionally approved bilingual safety benchmark CSV.
2. Place it at `data/processed/prompts.csv`.
3. Validate it before any activation extraction (see next section).

> The file `data/raw/prompts_template.csv` provides the schema with harmless examples
> and clearly marked placeholders. **Never commit** `data/processed/prompts.csv` to the
> repository — it is excluded by `.gitignore`.

## Reproducing the Experiments

All scripts use `PYTHONPATH=src` so that shared utilities in `src/common.py` resolve correctly.

### 1. Validate Dataset

```bash
PYTHONPATH=src python src/validate_dataset.py \
  --input data/processed/prompts.csv \
  --report results/tables/dataset_validation.json
```

The validator catches missing columns, blank values, invalid labels/splits, duplicate pair IDs,
pairs spread across splits, and warns about placeholder prompts or unverified translations. **Fix
all errors before proceeding.**

---

### 2. Extract Activations

Extract hidden-state activations for each combination of `{model} × {language} × {split}`.
Each run stores a `.npy` tensor of shape `[num_layers, num_examples, hidden_size]`.

```bash
# Example: Qwen2.5-7B-Instruct, English, training split
PYTHONPATH=src python src/extract_activations.py \
  --config configs/default.yaml \
  --dataset data/processed/prompts.csv \
  --model-id Qwen/Qwen2.5-7B-Instruct \
  --language en \
  --split train \
  --output-dir activations

# Repeat for all 12 combinations:
# models: Qwen/Qwen2.5-7B-Instruct, meta-llama/Meta-Llama-3-8B-Instruct
# languages: en, bn
# splits: train, validation, test
```

> **Memory tip:** Pass `--batch-size 1` if you hit GPU OOM errors regardless of the config value.

---

### 3. Analyze Directions

Compute per-layer DiM directions and descriptive metrics on the training split:

```bash
PYTHONPATH=src python src/analyze_directions.py \
  --config configs/default.yaml \
  --dataset data/processed/prompts.csv \
  --activation-dir activations \
  --activation-stem Qwen2.5-7B-Instruct_en_train \
  --output results/tables/qwen_en_directions.json
```

Outputs **balanced accuracy** and **ROC-AUC** at each layer. **Select your target layer
using validation data only** (not the test split). Record the chosen layer before opening
test results.

---

### 4. Cross-Language Comparison

After English and Bangla activations exist for both train and validation splits:

```bash
PYTHONPATH=src python src/compare_languages.py \
  --activation-dir activations \
  --source-en Qwen2.5-7B-Instruct_en_train \
  --source-bn Qwen2.5-7B-Instruct_bn_train \
  --target-en Qwen2.5-7B-Instruct_en_validation \
  --target-bn Qwen2.5-7B-Instruct_bn_validation \
  --layer 12 \
  --output results/tables/qwen_cross_language.json
```

Key output fields:
- `cosine_english_bangla` — alignment of EN and BN directions
- `english_direction_on_english` / `english_direction_on_bangla` — transfer scores
- `bangla_direction_on_bangla` / `bangla_direction_on_english` — transfer scores

---

### 5. Negative Controls

Run **all four controls** before drawing conclusions:

#### 5a. Shuffled-Label Null Distribution
```bash
PYTHONPATH=src python src/shuffled_label.py \
  --source-stem Qwen2.5-7B-Instruct_en_train \
  --target-stem Qwen2.5-7B-Instruct_en_validation \
  --layer 12 \
  --num-permutations 1000 \
  --output results/tables/shuffled_label_baseline.json
```

#### 5b. Random-Direction Null Distribution
```bash
PYTHONPATH=src python src/random_direction.py \
  --target-stem Qwen2.5-7B-Instruct_en_validation \
  --layer 12 \
  --num-directions 1000 \
  --output results/tables/random_direction_baseline.json
```

#### 5c. Language-Identity Direction (confirms EN≠BN signal is not just script)
```bash
PYTHONPATH=src python src/language_identity.py \
  --en-stem Qwen2.5-7B-Instruct_en_train \
  --bn-stem Qwen2.5-7B-Instruct_bn_train \
  --layer 12 \
  --harm-direction-en-json results/tables/qwen_en_directions.json \
  --harm-direction-bn-json results/tables/qwen_bn_directions.json \
  --output results/tables/language_identity_baseline.json
```

#### 5d. Layer-Mismatch Control (confirms transfer is layer-specific)
```bash
PYTHONPATH=src python src/layer_mismatch.py \
  --source-stem Qwen2.5-7B-Instruct_en_train \
  --target-stem Qwen2.5-7B-Instruct_en_validation \
  --layer 12 \
  --mismatch-layer 4 \
  --output results/tables/layer_mismatch_baseline.json
```

#### 5e. Topic Residualization (disentangles topic from harmfulness signal)
```bash
PYTHONPATH=src python src/topic_residualization.py \
  --stem Qwen2.5-7B-Instruct_en_train \
  --layer 12 \
  --num-topic-components 5 \
  --output results/tables/topic_residualized.json
```

#### 5f. Unrelated Semantic Contrast
```bash
PYTHONPATH=src python src/unrelated_semantic.py \
  --source-stem Qwen2.5-7B-Instruct_en_train \
  --category-a science \
  --category-b daily_life \
  --target-stem Qwen2.5-7B-Instruct_en_validation \
  --layer 12 \
  --output results/tables/unrelated_semantic_baseline.json
```

## Configuration

All hyperparameters live in [`configs/default.yaml`](configs/default.yaml):

| Section | Key | Default | Description |
|---|---|---|---|
| `project` | `seed` | `42` | Global RNG seed |
| `model` | `model_id` | `Qwen/Qwen2.5-7B-Instruct` | HF model checkpoint |
| `model` | `torch_dtype` | `bfloat16` | Weight precision |
| `model` | `device_map` | `auto` | Device placement |
| `extraction` | `batch_size` | `2` | Prompts per forward pass |
| `extraction` | `max_length` | `512` | Max tokenized length |
| `extraction` | `include_embedding_layer` | `false` | Whether layer 0 (embedding) is stored |
| `analysis` | `bootstrap_samples` | `1000` | Bootstrap replicates (future use) |
| `analysis` | `selected_layer` | `null` | Frozen validation-selected layer |
| `safety` | `allow_generation` | `false` | Guard: disables generative forward passes |

|---|---|

## Negative Control Baselines

| Control | Script | Purpose |
|---|---|---|
| Shuffled label | `shuffled_label.py` | Null distribution for transfer BA/AUC |
| Random direction | `random_direction.py` | Null distribution for cosine projection |
| Language identity | `language_identity.py` | Separates script-level from safety signal |
| Layer mismatch | `layer_mismatch.py` | Confirms transfer is layer-specific |
| Topic residualization | `topic_residualization.py` | Disentangles topic identity from harmfulness |
| Unrelated semantic | `unrelated_semantic.py` | Harmless-category contrast as lower bound |

A direction should exceed **all** of these baselines before cross-lingual refusal structure
is claimed.

## Recommended Next Steps

The scaffold is intentionally conservative. Before publication, add:

- **Assistant-region token pooling** — replace last-non-padding with the assistant-turn mean.
- **Bootstrap confidence intervals** — pair-level bootstrap over prompt pairs.
- **Prompt-length controls** — verify results hold when length is balanced.
- **Held-out test evaluation** — freeze the layer selection rule before running on test.
- **Behavioral refusal rubric** — human-reviewed behavioral annotation of model outputs.
- **Causal intervention** — bounded, pre-registered ablation studies on research-only checkpoints.
